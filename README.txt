JEE Solve V6 — Colourful Command Center
==========================================
Open index.html in a modern browser.

V6 design:
- Neon / glassmorphism command-center interface
- Colour-coded subject cards
- Animated preparation ring and momentum bar
- Question Lab with filters/search
- Chapter Map
- Timed Test Center
- Analytics dashboard
- Dark/light mode
- Local solved/bookmark/test storage
- Admin CMS prototype

IMPORTANT:
This is a front-end prototype. Admin data and progress are stored in localStorage and are NOT a secure
shared online database. Do not expose the admin page as a real production admin system.

For production V7:

- cloud progress sync

- SEO pages, sitemap, robots.txt

V6 QUESTION BANK EXPANSION
==========================
330 original JEE-style practice questions are bundled:
- Physics: 110
- Chemistry: 110
- Mathematics: 110

The questions are newly written practice content and are NOT presented as copied JEE PYQs.
Each question includes an answer, step-by-step solution and a JEE shortcut.
A static HTML page exists for every question so search engines can discover individual pages.
sitemap.xml and robots.txt are included.

PUBLIC WEBSITE
==============
To make the site available to everyone, upload this folder to a static hosting service such as GitHub Pages
or Cloudflare Pages. After you have a public URL, submit https://YOUR-DOMAIN/sitemap.xml in Google Search Console.
A public URL is required before Google can index the site.

IMPORTANT
=========
The Admin CMS is still a browser-local prototype. It is not a secure production admin system.
Do not call these questions official JEE PYQs.
